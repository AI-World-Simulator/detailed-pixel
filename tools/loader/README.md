# Лоадер: пиксельные жители на экране загрузки

Код — `src/loader.js` + `src/loader.css`, спрайты — `data/loader/sprites.json` (data URI, ~16 КБ).
`build.js` вставляет всё это в `index.html` прямо за разметкой `#loading`, до больших скриптов, поэтому сцена появляется раньше, чем браузер разберёт карту.

- Выбор сцены: `index.html?loader=crew|chat|walk|parade|island|dots` (по умолчанию `DEFAULT` в `loader.js`):
  **crew** — бригада строит мир по шагам загрузки; **chat** — двое болтают картинками в облачках; **walk** — житель идёт, пейзаж меняется по шагам;
  **parade** — жители идут через улицу; **island** — остров дорастает слоем на каждом шаге; **dots** — запасной без спрайтов.
- Медленная загрузка для настройки: `index.html?slowboot=8000` растягивает шаги `boot()` на 8 с (без бэкенда загрузка мгновенная).
- Все сцены рядом: `node tools/loader/demo.js` → `loaders.html` (шаги переключаются сами, клик по шагу — вручную).

## Как устроено

- `boot()` вызывает `LOADER.stage(key, text, i, n)` на каждом шаге (`coast, smooth, relief, roads, kit, workers, people`) и `LOADER.done()` в конце.
  Неизвестный ключ (например, будущая загрузка с бэкенда) даёт «общую суету» — сцену можно звать с любыми шагами.
- Сцена строится один раз на шаг: JS создаёт DOM и `@keyframes`, дальше двигает только CSS.
  Анимируются лишь `transform` и `opacity` — их считает compositor, поэтому сцена не замирает, пока главный поток занят
  (проверено: за 3 с блокировки главного потока Chrome отдал 52 разных кадра сцены).
- Кадр спрайта — окно `.lp` над лентой кадров `<i>`; смена кадра — `translateX(-k/n·100%)` с `step-end`, поэтому длительность каждого кадра своя (моргание 140 мс, реплика 110–190 мс).
- Масштаб только целый: `--s` = 3 (десктоп), 2 (≤560 px), 1 (≤351 px); все сдвиги кратны арт-пикселю, `image-rendering: pixelated`.
- Сцена показывается через 350 мс (быстрая загрузка не мигает полуначатой сценой), уход — затухание 0,35 с.
- `prefers-reduced-motion`: кадры и перемещения стоят, этапы сразу в конечном виде, вместо движения — пульсация прозрачности.

## Ассеты (всё делают открытые модели в ComfyUI, без ручного рисования)

```bash
PY=~/ComfyUI/.venv/bin/python
cd tools/loader/gen
python3 ../../ai/cgen.py jobs_z1.json out     # Z-Image-Turbo: линейка жителей
python3 ../../ai/cgen.py jobs_z2.json out     # Z-Image-Turbo: иконки, реквизит, декорации
python3 ../../ai/cgen.py jobs_z3.json out     # Z-Image-Turbo: остров
$PY ../../ai/anim.py split out/z_lineup_s1.png base/s1   # жители по одному на холсте 768×768 (вход для правок)
python3 ../../ai/cgen.py jobs_q2.json out     # Qwen-Image-2.1 edit: кадры действий (моргает, говорит, машет, копает…)
python3 ../../ai/cgen.py jobs_q3.json out     # Qwen-Image-2.1 edit: остров теряет слой за слоем (город → дороги → горы → луга → суша)
cd ../../.. && $PY tools/loader/assets.py && node build.js && node tools/loader/demo.js
```

- `tools/ai/cgen.py` — клиент API ComfyUI (127.0.0.1:8188), графы собираются в коде; задачи одной модели держите вместе.
- `tools/ai/anim.py` — из рендера в пиксели: средний шаг сетки (автокорреляция) + равномерная сетка с подобранной фазой, медиана клетки,
  удаление фона и тени заливкой от края (через тёмный контур не проходит), **одна палитра на все кадры персонажа**, совмещение кадра
  с базовым по совпадению цветов; для правок лица (`blink/talk/laugh`) всё ниже головы берётся из базового кадра.
- `tools/loader/assets.py` — имена объектов листов, список кадров; `LDR_SKIP=boy:crouch` выкидывает неудачный кадр.
- `tools/loader/pack.py` — ленты кадров и реквизит в индексированные PNG → `data/loader/sprites.json`.
- Персонажи ставятся по центру тела базового кадра (`cx`) и по линии ног (`feet`): холст персонажа — объединение всех кадров
  (поднятая лопата расширяет его в одну сторону), поэтому левый край холста для раскладки не годится.
- Светлые предметы (газета) цветовое удаление фона съедает — для таких кадров маска BiRefNet: `cgen.py` с `"kind": "bgmask"`
  → `gen/out/m_<житель>_<кадр>.png`, `assets.py` подхватит её сам.

## Добавить сцену

`V.<name> = function (sc) { … return { stage: function (key, i, n) { … } }; }` в `loader.js`; помощники:
`sprite(sc, name, x, y, flip)`, `frames(s, [[кадр, мс], …])`, `motion(s, [[[dx, dy], мс], …])`, `fade(el, [[0|1, мс], …])`,
`talk(мс)`, `loop(a, b, мс, всего)`, `idleBlink(s, всего, когда)`. Координаты — арт-пиксели от левого нижнего угла сцены 168×72.
