ЛОАДЕРЫ

Сцены из пиксельных жителей для экрана загрузки. Всё движение — CSS (transform/opacity), поэтому сцена не замирает, пока главный поток занят генерацией мира. Шаги переключаются сами каждые 2,2 с; клик по шагу — вручную. Режим «меньше движения» проверяется в DevTools → Rendering → prefers-reduced-motion.

Бригада?loader=crew

Каждый шаг загрузки — своя работа: красят сушу, копают горы, кладут дорогу, распаковывают ящик, встречают жителей. Сделанное остаётся на сцене.

в приложении (8 с)

Болтовня?loader=chat

Двое соседей под фонарём обмениваются картинками в облачках, смеются, моргают. Не зависит от шагов, цикл 14 с.

в приложении (8 с)

Прогулка?loader=walk

Житель идёт через мир; пейзаж за спиной меняется по шагам: море → горы → дороги → город.

в приложении (8 с)

Шествие?loader=parade

Жители идут через улицу, у каждого свой шаг; старик читает газету у скамейки. Не зависит от шагов.

в приложении (8 с)

Остров?loader=island

Остров «дорастает» слоем на каждом шаге: море → пляж → луга → горы и лес → дороги → дома.

в приложении (8 с)

Точки?loader=dots

Запасной вариант без спрайтов (и для старых браузеров).
